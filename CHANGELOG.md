# Changelog

- Initial MVP for JSON-Schema-driven Eta template IntelliSense
- Added file-header pragma parsing for `@schema` and `@root`
- Added local schema loading with local `$ref` and `$defs` resolution
- Added dot-path and quoted bracket-path completion, hover, and invalid-path diagnostics
- Added schema-change invalidation and document refresh behavior
- Added native Node v24 TypeScript tests and example fixtures
